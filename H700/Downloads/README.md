# H700 Release Packages

This directory keeps versioned PegasusG by ROC frontend packages for H700.
Only formal packages named like the following should be committed:

```text
PegasusG by ROC ver1.08 for H700.zip
PegasusG by ROC ver1.09 for H700.zip
```

New builds must increment the version number. Do not overwrite an existing
release archive. The same ZIP should also be attached to the matching GitHub
Release tag, for example `v1.08`.

The complete music supplement is intentionally not committed because of its
size and uncertain redistribution status. Every formal frontend package still
contains the selected 11-track built-in music set.
